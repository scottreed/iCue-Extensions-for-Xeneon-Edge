# Tinkerer skills - my build notes (written by me)
Game: Ember Harbor (PC). The Tinkerer skill tree, 8 skills. You have 12 skill points in total.

| Skill | Max points | Needs | What it does |
|---|---|---|---|
| Spark | 3 | none | +10% fire damage per point |
| Ignite | 2 | Spark | Fire attacks set enemies burning |
| Blaze | 1 | Ignite | Burning enemies take double damage |
| Sprint | 3 | none | +5% move speed per point |
| Vault | 1 | Sprint | Jump over low cover |
| Grit | 3 | none | +10 max health per point |
| Brace | 2 | Grit | Take 20% less damage when blocking |
| Second wind | 1 | Brace | Recover 30% health once per fight |

## Builds I use
**Fire build**: Spark 3, Ignite 3, Blaze 1, Grit 2, Sprint 1.
**Runner build**: Sprint 3, Vault 1, Grit 3, Brace 2, Second wind 1, Spark 1.

Use warm colours, nothing fancy.
