# What a complete guide covers

The goal of this skill is a guide a player can keep open beside the game and not need anything else: every question they would normally look up should be answered in it. Build toward that by default. Narrow the scope only when the user explicitly asks for less, and then say in the outline what is left out.

## Coverage categories
Work through these for the game, decide for each one "included", "not applicable to this game" or "left out (reason)", and record that table in `outline.md`. Do not drop a category silently.

| Category | What "complete" means | Typical guide form |
|---|---|---|
| Story walkthrough | Every story mission or chapter, in order, with the steps to complete it, the optional objectives and how to meet them, and common failure points | One page per mission or chapter, chained per sequence; steps ticked off through a tracker |
| Side content | Every side quest, contract, challenge, activity and event type: where to start it, what it needs, the reward, the steps | Pages or a tracker per type |
| Collectibles | Every collectible type with total count, where each one is, how to get it (any gate, key, tool or story point needed), and its reward | One tracker per type grouped by area or region; map pins only from supplied coordinates |
| Areas and hubs | What is in each area or region: vendors, fast travel, activities, collectible counts, unlock requirements | One page per area with a table of what is there and links to the trackers |
| Bosses, ship fights and set pieces | How each works, its phases or tells, what to bring, the reliable way to win, rewards | One page per fight, linked from the mission |
| Progression and economy | Upgrades, crafting, shops, currencies, skills, gear: costs, effects, best order to unlock | Tables and skill trees, short "what to buy first" pages |
| Missables and points of no return | Everything that can be permanently lost or locked, and when | Callouts on the mission page plus one missables tracker |
| Pain points | The parts players get stuck on or look up most: confusing objectives, hard sections, hidden requirements, common mistakes, controls and mechanics that the game explains poorly | Callouts and tips on the relevant page, plus a "Common problems" page |
| Achievements / trophies | The full list, how to earn each, which are missable | A tracker |
| Reference | Controls, glossary, item and enemy tables, difficulty and mode notes | Pages, tables, glossary |

## Finding the material
- Start from several guide sites and a community wiki for the same game and version. One source rarely covers all categories; where they disagree, say so in your notes and prefer the more specific, more recent one, or record both.
- Look for the pain points deliberately: search for "common mistakes", "tips", "missable", "stuck", "hardest" for the game, and read the walkthrough steps for the hard sections (stealth, timed objectives, optional objectives that fail easily).
- Check the version: remasters, remakes and patches change maps, counts and mission details. Use sources for the same version and say in the guide which version it describes.
- Fetch the pages that hold the details (per mission, per region), not just the overview pages. For big games divide the research (by sequence or by region) between helper agents and have each write structured notes in your own words, then assemble.

## Honest limits
If a category cannot be filled reliably (no source gives per-item locations, or sources contradict each other), say exactly that in the outline and in the final report, name what you tried, and leave out only the part you cannot support. Never fill a gap with a guess, and never present a partial list as complete: label counts and coverage plainly ("21 of 30 listed; the source names only these").

## Report at the end
Include the coverage table with a status per category, the counts (missions, steps, collectible items per type, tables), and the list of known gaps, so the user sees what the guide can and cannot answer before they rely on it in the game.
